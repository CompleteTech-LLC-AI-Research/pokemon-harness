## Teeth, and no over-rejection

Real opt-outs, each expected red and confirmed red:

```
# ruff: noqa     F      # ruff: noqa: F821   F
# flake8: noqa   F      # fmt: off           F
```

Inert forms, expected green:

```
# noqa: E501               green  (bare `# noqa: CODE` is not file-scoped in Ruff)
# RUFF: NOQA               green  (case-sensitive in Ruff's parser)
```

One form I want on the record because it looks like over-rejection and is not:

```
# ruff: noqa is prose here   RED
```

That is deliberate and documented in the commit and in the row's comment: the
predicate is now "does this comment stop the lane catching the probe it placed
there", not "does this text match a known directive". A bare `# ruff: noqa`
comment *does* silence a real file, so refusing it is correct — the test file
here is stdin, and Ruff's own parser decides what it honours, not the author's
guess at a spelling list. A `# noqa: E501` comment stays green precisely because
Ruff does not honour it.

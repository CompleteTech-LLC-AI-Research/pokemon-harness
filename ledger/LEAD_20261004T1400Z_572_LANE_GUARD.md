## No false positive on legitimate suppressions

All 34 selective directives are allowed, because each is load-bearing rather than
decorative. Verified directly on the file the PR names:

    tests/_sentinel_support_part1.py line 2:  # ruff: noqa: F821
    stripped -> Counter({'F821': 105})

Exactly the **105 F821s** the PR claims. These are generated
`tests/_sentinel_support_*` fragments whose names are supplied by an assembled
module, so a blanket "no file-level directive" rule would be wrong, not merely
strict. The PR is right to scope the allowance by re-measuring rather than
hard-coding an allowlist.

## Stale allowances are caught

Mutating the same directive to `# ruff: noqa: F821, F841` — naming a code the
file does not report once the directive is gone — turns the row **red**. So the
row cannot be satisfied by deleting real ignores, and it cannot rot into a
permanent exemption.

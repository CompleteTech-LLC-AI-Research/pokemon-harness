## Three findings

**1. Six module docstrings were silently not docstrings** (17 E402s). Each of
these files placed its module docstring after `from __future__ import
annotations`, so `__doc__` was `None` and the documentation was a no-op
expression. Fixing this restores real docstrings. AST otherwise identical.

**2. Three rows matched path literals.** `test_matrix_benchmark_is_linted_by_every_main_ruff_lane`,
`test_main_ruff_lanes_run_in_executable_control_flow` and
`test_main_ruff_lanes_stop_the_local_runner_on_failure` asserted
`_BENCHMARK in lane`, which is false once the lane passes the `scripts` directory
token — even though coverage is unchanged. This is the same weakness `25607fc`
repaired in `tests/test_stepping_loop_profile.py`; these three were missed, so
#569 as written would have *removed* three working guards. `_lane_covers()` now
asks Ruff via `--show-files --force-exclude` per path token and handles both lane
shapes.

Two bugs of my own surfaced while writing that helper and are worth recording:
`--show-files` emits **absolute** paths (comparing against a relative name made
the resolver report false negatives), and a recorded runner vector starts at
`-m ruff`, not `python`, so a fixed offset mis-parsed it. Both are fixed.

**3. Format lane closed.** `scripts/full_to_brock.py` and
`tests/_tcp_trade_peer_drive_setup.py` were one stray blank line short; both are
AST-identical to master after formatting.

## What is deliberately NOT in this PR

`ruff check scripts tests --no-cache` still exits 1 with **113 errors**
(113x E402, 22x E731, 5x F811). Only the E402s from the docstring bug are fixed;
the rest are three distinct categories:

- ordinary lint findings in newly-covered files (E731, F811) — fixable directly
- `sys.path` bootstrap imports that must stay below the `sys.path.insert`
- documented post-split re-exports at end-of-file that preserve module surface
  and the `gate.<name>` monkeypatch targets the tests rely on

The latter two are not defects. Making the lane green needs a **scoped, measured
`per-file-ignores` allowance pinned by a policy row** — the approach #572 uses
for selective suppressions — not a mass edit. That is separate work needing its
own review, so #567 stays open.

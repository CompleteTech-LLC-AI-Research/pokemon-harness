Root cause: this stack's two `scripts/` rows still called the helper in the pre-#572
single-argument form. A bare string binds to `paths`, so `"scripts"` unpacked into its seven
characters; Ruff was asked to check `s`,`c`,`r`,`i`,`p`,`t`,`s` as paths, resolved none, and both
rows reported that all 100+ scripts were excluded from the gate. The rows were not wrong about the
boundary — they were measuring a string as a path list. Fixed at both call sites, one line each:

```python

```

- `tests/test_stepping_loop_profile.py` (`_ruff_resolved_scripts()`, which reuses the helper)

# #385 — a completed loop's target is read as its LAST element

Head: `5b46d22` (branch `fix/385-position-aware-loop-value`, base `0c2ba4d`)
Worktree: `/home/agent/poke-harness/wt-385-posvalue`

## The defect

`_raw_store_values` records a `for` target only when the iterable is a literal
with **exactly one** element, and declines a multi-element one:

```python
for cs in (contextlib.nullcontext(), contextlib.suppress(AssertionError)):
    pass
with cs:                 # `cs` is the LAST element, the suppressor
    assert x == 99       # executed: swallowed
```

Executed, that assert never fires. The analyzer had no recorded binding for
`cs`, so the header read as an ordinary unbound name and reported `enforced` —
certifying a disarmed contract as load-bearing (#308 criterion 1).

## Why the existing refusal is right and stays

Inside the body the target holds a **different** value per iteration:

```python
for cs in (contextlib.suppress(AssertionError), contextlib.nullcontext()):
    with cs:
        assert 1 == 2
```

First pass swallows, second does not. No single static answer is right, and
guessing lands on a false verdict half the time. Declining keeps the assert
`enforced`, the safe direction. `_single_loop_element` is untouched.

## The design: separate by POSITION, do not average

After the loop runs to exhaustion the target holds the **final** element, and
that is the same answer on every path — the property the in-body case lacks.
Three conditions gate it, each with a CONTROL row:

| Condition | Rationale |
|---|---|
| loop precedes the header in the block that sequences them | a loop written after the header has not run |
| loop can run to exhaustion (no `break`) | a break leaves the target mid-iteration |
| body does not rebind the name | the body runs after the target on every pass |
| no later store supersedes it | includes a *conditional* store, where the two paths disagree |

A loop's `else` arm is the **same** question — it runs only once the iterable
is exhausted — so it is handled here too, not grouped with the body.
